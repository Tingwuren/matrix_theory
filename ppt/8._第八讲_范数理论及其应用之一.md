## 引言：为什么需要范数？

在线性代数中，我们经常需要度量向量的"大小"或两个向量之间的"距离"。范数就是这样一个工具，它将向量映射到非负实数，从而量化向量的"长度"。

**范数的应用场景**：
- **数值分析**：衡量误差大小、判断迭代算法收敛性
- **信号处理**：信号能量、功率的度量
- **机器学习**：正则化（L1、L2正则化）、损失函数设计
- **优化问题**：约束条件的表达、收敛性分析

## 一、向量范数的定义

### 1.1 范数的公理化定义

**定义**：如果 $V$ 是数域 $K$ 上的线性空间，且对于 $V$ 的任一向量 $x$，对应一个实数值 $\|x\|$，满足以下三个条件

1) **非负性（正定性）**：$\|x\| \geq 0$，且 $\|x\| = 0 \Leftrightarrow x = 0$

2) **齐次性（绝对一次齐次性）**：$\|kx\| = |k| \cdot \|x\|, \; \forall k \in K$

3) **三角不等式（次可加性）**：$\|x + y\| \leq \|x\| + \|y\|$

则称 $\|x\|$ 为 $V$ 上向量 $x$ 的**范数**，简称为**向量范数**。

> **注意**：2) 中 $|k|$ 当 $K$ 为实数域时为绝对值，当 $K$ 为复数域时为复数的模。

### 1.2 直观理解

| 性质 | 直观含义 | 类比 |
|------|----------|------|
| 非负性 | 长度不能为负，只有零向量长度为零 | 物理距离不能为负 |
| 齐次性 | 向量伸缩 $k$ 倍，长度也伸缩 $\|k\|$ 倍 | 弹簧拉伸比例 |
| 三角不等式 | 两边之和大于第三边 | 走两条边比走斜边长 |

**几何解释**（以 $\mathbb{R}^2$ 为例）：

三角不等式的几何意义是：从原点到点 $x+y$，直接走（即 $\|x+y\|$）不会比先走到 $x$ 再走到 $x+y$（即 $\|x\| + \|y\|$）更远。

```
        y
       /|
      / |
     /  |
    /   |
   x----x+y
   
||x + y|| ≤ ||x|| + ||y||
```

### 1.3 范数的基本性质

**向量的范数具有下列简单性质**：

**(1) 单位化性质**：当 $\|x\| \neq 0$ 时，$\left\|\frac{1}{\|x\|}x\right\| = 1$

$$\because \left\|\frac{1}{\|x\|}x\right\| = \frac{1}{\|x\|}\|x\| = 1$$

> 💡 **理解**：任何非零向量除以它的范数后，得到一个"单位向量"（范数为1的向量）。这在很多应用中非常有用，比如归一化处理。

**(2) 对称性**：$\forall x \in V$，$\|-x\| = \|x\|$

$$\because \|-x\| = |-1| \|x\| = \|x\|$$

> 💡 **理解**：向量反向不改变其"长度"，这与我们对长度的直观认识一致。

**(3) 逆三角不等式（弱形式）**：$\forall x, y \in V$，$\|x\| - \|y\| \leq \|x - y\|$

$$\because \|x\| = \|(x - y) + y\| \leq \|x - y\| + \|y\| \Rightarrow \|x\| - \|y\| \leq \|x - y\|$$

**(4) 逆三角不等式（强形式）**：$\forall x, y \in V$，$\left| \|x\| - \|y\| \right| \leq \|x - y\|$

$$\|x\| = \|(x - y) + y\| \leq \|x - y\| + \|y\| \Rightarrow \|x\| - \|y\| \leq \|x - y\|$$

同样 $\|y\| - \|x\| \leq \|y - x\| = \|x - y\|$

> 💡 **理解**：两个向量范数的差的绝对值，不超过它们差向量的范数。这意味着**范数函数是连续的**：如果 $x$ 和 $y$ 很接近（$\|x-y\|$ 小），那么它们的范数也很接近（$|\|x\|-\|y\||$ 小）。

### 1.4 距离的概念

由范数可以诱导出**距离**（度量）：

$$d(x, y) = \|x - y\|$$

这个距离满足度量空间的三条公理：
1. $d(x,y) \geq 0$，且 $d(x,y) = 0 \Leftrightarrow x = y$（非负性）
2. $d(x,y) = d(y,x)$（对称性）
3. $d(x,z) \leq d(x,y) + d(y,z)$（三角不等式）

## 二、向量范数的例子

### 2.1 $\mathbb{C}^n$ 空间中的常用范数

**例 1**：线性空间 $\mathbb{C}^{n}$，设 $x = (x_{1}, x_{2}, \cdots, x_{n})^{T} \in \mathbb{C}^{n}$

**① 1-范数（曼哈顿范数/出租车范数）**：

$$\|x\|_{1} = \sum_{i=1}^{n} |x_{i}|$$

> 💡 **几何意义**：在二维平面上，从原点到点 $(x_1, x_2)$，沿着坐标轴走的总距离。想象在曼哈顿街区，只能沿着街道（水平或垂直）行走。
>
> **应用**：L1正则化（Lasso回归），促进稀疏性。

**② 2-范数（欧几里得范数）**：

$$\|x\|_{2} = \sqrt{(x, x)} = \sqrt{\sum_{i=1}^{n} |x_i|^2}$$

> 💡 **几何意义**：就是我们熟悉的欧几里得距离，即向量的"真实长度"。
>
> **应用**：L2正则化（岭回归），信号能量计算。

**③ $\infty$-范数（最大范数/切比雪夫范数）**：

$$\|x\|_{\infty} = \max_{i} |x_{i}|$$

> 💡 **几何意义**：各分量绝对值中的最大值。在二维平面上，$\|x\|_\infty = 1$ 的点集是一个正方形。
>
> **应用**：衡量最坏情况下的误差。

**④ $p$-范数（$l_p$ 范数）**：

$$\|x\|_{p} = \left( \sum_{i=1}^{n} |x_{i}|^{p} \right)^{\frac{1}{p}} \; (1 \leq p < \infty)$$

> 💡 **说明**：1-范数、2-范数、$\infty$-范数都是 $p$-范数的特例。当 $p \to \infty$ 时，$\|x\|_p \to \|x\|_\infty$。

### 2.2 不同范数的"单位球"可视化

在 $\mathbb{R}^2$ 中，不同范数下 $\|x\| = 1$ 的点集形状不同：

| 范数 | 单位球形状 | 图示 |
|------|-----------|------|
| $\|\cdot\|_1$ | 菱形（旋转45°的正方形） | ◇ |
| $\|\cdot\|_2$ | 圆形 | ○ |
| $\|\cdot\|_\infty$ | 正方形 | □ |
| $\|\cdot\|_p$ ($1<p<2$) | 介于菱形和圆之间 | - |
| $\|\cdot\|_p$ ($2<p<\infty$) | 介于圆和正方形之间 | - |

### 2.3 具体计算示例

**例**：设 $x = (3, -4)^T \in \mathbb{R}^2$，计算各种范数：

- $\|x\|_1 = |3| + |-4| = 3 + 4 = 7$
- $\|x\|_2 = \sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$
- $\|x\|_\infty = \max\{|3|, |-4|\} = \max\{3, 4\} = 4$
- $\|x\|_3 = (|3|^3 + |-4|^3)^{1/3} = (27 + 64)^{1/3} = 91^{1/3} \approx 4.50$

### 2.4 $p$-范数满足范数条件的证明

**证明**：向量 $p$-范数 $\|x\|_{p} = \left( \sum_{i=1}^{n} |x_{i}|^{p} \right)^{\frac{1}{p}} \; (1 \leq p < \infty)$

**证**：性质 (1)、(2) 显然是满足的

> **验证非负性**：由于 $|x_i|^p \geq 0$，所以 $\sum |x_i|^p \geq 0$，从而 $\|x\|_p \geq 0$。
> 
> 当 $\|x\|_p = 0$ 时，$\sum |x_i|^p = 0$，由于每项非负，必有每项为零，即 $x_i = 0$，所以 $x = 0$。
>
> **验证齐次性**：$\|kx\|_p = (\sum |kx_i|^p)^{1/p} = (\sum |k|^p|x_i|^p)^{1/p} = |k|(\sum |x_i|^p)^{1/p} = |k|\|x\|_p$

**验证三角不等式**（这是最难的部分）：

设 $x = \left( {{\xi }_{1},{\xi }_{2},\cdots ,{\xi }_{n}}\right) , y = \left( {{\eta }_{1},{\eta }_{2},\cdots ,{\eta }_{n}}\right)$ ,则

**情况1**：当 $p = 1$ 时，直接利用绝对值的三角不等式：

$$
\|x + y\|_{1} = \sum \left| {{\xi }_{i} + {\eta }_{i}}\right|  \leq  \sum \left( \left| {\xi }_{i}\right|  + \left| {\eta }_{i}\right| \right)  = \|x\|_{1} + \|y\|_{1}
$$

**情况2**：当 $p > 1$ 时：

- 若 $x + y = \theta$（零向量），结论显然成立
- 若 $x + y \neq \theta$，需要借助 **Hölder 不等式**

#### Hölder 不等式（重要工具）

$$
\sum_{i=1}^{n} \left| {{a}_{i}{b}_{i}}\right|  \leq  {\left( \sum_{i=1}^{n} {\left| {a}_{i}\right| }^{p}\right) }^{\frac{1}{p}}{\left( \sum_{i=1}^{n} {\left| {b}_{i}\right| }^{q}\right) }^{\frac{1}{q}}
$$

其中 $p > 1, q > 1$，且 $\frac{1}{p} + \frac{1}{q} = 1$（称 $p$ 和 $q$ 为**共轭指数**）。

> 💡 **理解 Hölder 不等式**：
> - 当 $p = q = 2$ 时，就是熟悉的 **Cauchy-Schwarz 不等式**：$|\langle a, b \rangle| \leq \|a\|_2 \|b\|_2$
> - 可以理解为：内积的大小受两个向量各自范数的约束

由 $\frac{1}{q} = 1 - \frac{1}{p} = \frac{p - 1}{p}$，可得 $(p - 1)q = p$

**推导过程**：

$$\|x + y\|_{p}^{p} = \sum_{i = 1}^{n}{\left| {\xi }_{i} + {\eta }_{i}\right| }^{p} = \sum_{i = 1}^{n}\left( {\left| {{\xi }_{i} + {\eta }_{i}}\right|  \cdot  {\left| {\xi }_{i} + {\eta }_{i}\right| }^{p - 1}}\right)$$

利用 $|{\xi }_{i} + {\eta }_{i}| \leq |{\xi }_{i}| + |{\eta }_{i}|$：

$$\leq  \sum_{i = 1}^{n}\left| {\xi }_{i}\right| {\left| {\xi }_{i} + {\eta }_{i}\right| }^{p - 1} + \sum_{i = 1}^{n}\left| {\eta }_{i}\right| {\left| {\xi }_{i} + {\eta }_{i}\right| }^{p - 1}$$

对每个求和式应用 Hölder 不等式：

$$\leq  {\left( \sum_{i = 1}^{n}{\left| {\xi }_{i}\right| }^{p}\right) }^{1/p}{\left( \sum {\left( {\left| {\xi }_{i} + {\eta }_{i}\right| }^{p - 1}\right) }^{q}\right) }^{1/q} + {\left( \sum_{i = 1}^{n}{\left| {\eta }_{i}\right| }^{p}\right) }^{1/p}{\left( \sum {\left( {\left| {\xi }_{i} + {\eta }_{i}\right| }^{p - 1}\right) }^{q}\right) }^{1/q}$$

由于 $(p-1)q = p$，有 $(|{\xi }_{i} + {\eta }_{i}|^{p-1})^q = |{\xi }_{i} + {\eta }_{i}|^{p}$：

$$= \|x\|_{p}{\left( \sum {\left| {\xi }_{i} + {\eta }_{i}\right| }^{p}\right) }^{1/q} + \|y\|_{p}{\left( \sum {\left| {\xi }_{i} + {\eta }_{i}\right| }^{p}\right) }^{1/q}$$

$$= \left( {\|x\|_{p} + \|y\|_{p}}\right) \cdot \|x + y\|_{p}^{p/q} = \left( {\|x\|_{p} + \|y\|_{p}}\right) \cdot \|x + y\|_{p}^{p - 1}$$

因此：$\|x + y\|_{p}^{p} \leq \left( {\|x\|_{p} + \|y\|_{p}}\right) \cdot \|x + y\|_{p}^{p - 1}$

两边除以 $\|x + y\|_{p}^{p - 1}$（当 $x + y \neq \theta$ 时）：

$$\|x + y\|_{p} \leq \|x\|_{p} + \|y\|_{p}$$

这就是著名的 **Minkowski 不等式**，证明了 $p$-范数满足三角不等式。 ∎

### 2.5 其他线性空间中的范数

**例 2（有限维线性空间的范数）**：线性空间 $V^{n}$ 中，任取它的一组基 $x_{1}, \cdots, x_{n}$，则对于任意向量 $x$，可以表示为

$$
x = \xi_{1} x_{1} + \cdots + \xi_{n} x_{n}
$$

与 $\alpha = (\xi_{1}, \cdots, \xi_{n})^{T} \in \mathbb{C}^{n}$ 是同构的

所以 $\|x\|_{p} = \|\alpha\|_{p}$ 是 $V^{n}$ 中元素 $x$ 的 $p$-范数

> 💡 **关键思想**：有限维线性空间与 $\mathbb{C}^n$（或 $\mathbb{R}^n$）同构，所以可以通过坐标向量来定义范数。选取不同的基会得到不同的范数，但它们都是等价的（后面会证明）。

---

**例 3（函数空间的范数）**：$C[a, b]$ 为闭区间 $[a, b]$ 上的所有实连续函数所成线性空间，可以验证以下定义式均满足范数条件

**① 函数的 1-范数**：

$$
\|f(x)\|_{1} = \int_{a}^{b} |f(x)| dx
$$

> 💡 **几何意义**：函数曲线与 $x$ 轴之间的面积（取绝对值）。

**② 函数的 $\infty$-范数（上确界范数）**：

$$
\|f(x)\|_{\infty} = \max_{x \in [a, b]} |f(x)|
$$

> 💡 **几何意义**：函数图像距离 $x$ 轴的最大距离。

**③ 函数的 $p$-范数**：

$$
\|f(x)\|_{p} = \left( \int_{a}^{b} |f(x)|^{p} dx \right)^{\frac{1}{p}}, \quad 1 < p < \infty
$$

> 💡 **说明**：这是向量 $p$-范数向无限维空间的推广，求和变成了积分。当 $p = 2$ 时，$\|f\|_2^2 = \int_a^b |f(x)|^2 dx$ 表示信号的**能量**。

---

**例 4（加权范数/椭圆范数）**：设 $A$ 为 $n$ 阶实对称正定矩阵，对 $x \in \mathbb{R}^{n}$，定义：

$$\|x\|_{A} = (x^{T}Ax)^{1/2} = \sqrt{x^T A x}$$

称为**加权范数**或**椭圆范数**。

> 💡 **为什么叫椭圆范数**：在 $\mathbb{R}^2$ 中，$\|x\|_A = 1$ 的点集是一个椭圆（一般不是圆）。矩阵 $A$ 决定了椭圆的形状和方向。

**验证这是范数**：

**① 非负性**：由正定矩阵定义可知：
- $x^T A x \geq 0$，所以 $\|x\|_{A} \geq 0$
- $\|x\|_{A} = 0 \Leftrightarrow x^T A x = 0 \Leftrightarrow x = 0$（正定性）

**② 齐次性**：对任意数 $\alpha \in \mathbb{R}$，有

$$
\|\alpha x\|_{A} = \sqrt{(\alpha x)^{T}A(\alpha x)} = \sqrt{\alpha^{2} x^{T}Ax} = |\alpha| \sqrt{x^{T}Ax} = |\alpha| \|x\|_{A}
$$

**③ 三角不等式**：这需要一些技巧。

由 $A$ 正定且实对称 $\Rightarrow$ 存在正交矩阵 $Q$，使得

$$
Q^{T}AQ = \operatorname{diag}\left( {\lambda}_{1},\cdots ,{\lambda}_{n}\right) ,\;{\lambda}_{i} > 0, \; i = 1,\cdots ,n
$$

定义 $B = \operatorname{diag}\left( \sqrt{{\lambda}_{1}},\cdots ,\sqrt{{\lambda}_{n}}\right) Q^{T}$，可得 $A = B^{T}B$

> 💡 **理解**：任何正定矩阵都可以分解为 $A = B^T B$ 的形式（类似于 Cholesky 分解）。

因此：

$$
\|x\|_{A} = (x^{T}B^{T}Bx)^{1/2} = [(Bx)^{T}(Bx)]^{1/2} = \|Bx\|_{2}
$$

这说明 $\|x\|_A$ 就是 $Bx$ 的 2-范数！于是三角不等式的验证变得简单：

$$
\|x + y\|_{A} = \|B(x + y)\|_{2} \leq \|Bx\|_{2} + \|By\|_{2} = \|x\|_{A} + \|y\|_{A}
$$

---

**例 5（由线性变换诱导的范数）**：设 $\|y\|_{\alpha}$ 是 $\mathbb{C}^{m}$ 中的一个向量范数，给定矩阵 $A \in \mathbb{C}^{m \times n}$，它的 $n$ 个列向量线性无关（即 $A$ 是**列满秩**的）。

对于 $\mathbb{C}^{n}$ 中的一个向量 $x = (\xi_{1}, \xi_{2}, \cdots, \xi_{n})^{T}$，规定：

$$\|x\|_{\beta} = \|Ax\|_{\alpha}$$

则 $\|x\|_{\beta}$ 也是 $\mathbb{C}^{n}$ 中的一个向量范数。

> 💡 **关键条件**：$A$ 必须是列满秩的。如果 $A$ 不是列满秩，存在非零向量 $x$ 使得 $Ax = 0$，那么 $\|x\|_\beta = \|Ax\|_\alpha = 0$ 但 $x \neq 0$，违反非负性条件。

**证明**：

**① 非负性**：设 $A = (a_{1}, a_{2}, \cdots, a_{n})$，由假设知 $a_{1}, a_{2}, \cdots, a_{n}$ 线性无关。

当 $x \neq 0$ 时：
$$Ax = (a_{1}, \cdots, a_{n}) \begin{pmatrix} \xi_{1} \\ \xi_{2} \\ \vdots \\ \xi_{n} \end{pmatrix} = a_{1}\xi_{1} + \cdots + a_{n}\xi_{n} \neq 0$$

（因为列向量线性无关，非零线性组合不为零）

又因为 $\|y\|_{\alpha}$ 是 $\mathbb{C}^{m}$ 中的一个向量范数，有 $\|Ax\|_{\alpha} > 0$，即 $\|x\|_{\beta} > 0$

当 $x = 0$ 时，$Ax = 0$，所以 $\|x\|_{\beta} = \|Ax\|_{\alpha} = 0$

**② 齐次性**：$\forall k \in \mathbb{C}$，

$$\|kx\|_{\beta} = \|A(kx)\|_{\alpha} = \|kAx\|_{\alpha} = |k| \|Ax\|_{\alpha} = |k| \|x\|_{\beta}$$

**③ 三角不等式**：$\forall x, y \in \mathbb{C}^{n}$，

$$\|x + y\|_{\beta} = \|A(x + y)\|_{\alpha} = \|Ax + Ay\|_{\alpha} \leq \|Ax\|_{\alpha} + \|Ay\|_{\alpha} = \|x\|_{\beta} + \|y\|_{\beta}$$

因此 $\|x\|_{\beta}$ 是 $\mathbb{C}^{n}$ 中的一个向量范数。 ∎

> 💡 **总结**：当给定列满秩矩阵 $A \in \mathbb{C}^{m \times n}$ 时，可以由 $\mathbb{C}^{m}$ 中的一个向量范数诱导出 $\mathbb{C}^{n}$ 中的一个向量范数。这是构造新范数的重要方法。

## 三、范数等价

### 3.1 范数等价的定义

**定义**：有限维线性空间 $V^{n}$ 中任意两个向量范数 $\|x\|_{\alpha}$ 和 $\|x\|_{\beta}$，如果存在着正常数 $c_{1}$ 和 $c_{2}$，使得

$$
c_{1}\|x\|_{\beta} \leq \|x\|_{\alpha} \leq c_{2}\|x\|_{\beta} \quad (\forall x \in V^{n})
$$

则称范数 $\|x\|_{\alpha}$ 与 $\|x\|_{\beta}$ **等价**。

> 💡 **直观理解**：两个范数等价意味着它们对向量"大小"的度量是**相互可控**的。一个范数大，另一个范数也相应地大（可能差一个常数倍）。

### 3.2 等价关系的性质

范数等价是一个**等价关系**，满足：

**(1) 自反性**：任何范数与自身等价

$$1 \cdot \|x\|_{\alpha} \leq \|x\|_{\alpha} \leq 1 \cdot \|x\|_{\alpha}, \quad \forall x \in V^{n}$$

**(2) 对称性**：若 $\|\cdot\|_\alpha$ 与 $\|\cdot\|_\beta$ 等价，则 $\|\cdot\|_\beta$ 与 $\|\cdot\|_\alpha$ 也等价

由 $c_{1}\|x\|_{\beta} \leq \|x\|_{\alpha} \leq c_{2}\|x\|_{\beta}$ 可得：

$$\frac{1}{c_{2}}\|x\|_{\alpha} \leq \|x\|_{\beta} \leq \frac{1}{c_{1}}\|x\|_{\alpha}, \quad \forall x \in V^{n}$$

**(3) 传递性**：若 $\|\cdot\|_\alpha$ 与 $\|\cdot\|_\beta$ 等价，且 $\|\cdot\|_\beta$ 与 $\|\cdot\|_\gamma$ 等价，则 $\|\cdot\|_\alpha$ 与 $\|\cdot\|_\gamma$ 也等价

$$
\left. \begin{array}{l} c_{1}\|x\|_{\beta} \leq \|x\|_{\alpha} \leq c_{2}\|x\|_{\beta} \\  c_{3}\|x\|_{\gamma} \leq \|x\|_{\beta} \leq c_{4}\|x\|_{\gamma} \end{array}\right\} \quad \forall x \in V^{n}
$$

$$
\Rightarrow c_{1}c_{3}\|x\|_{\gamma} \leq \|x\|_{\alpha} \leq c_{2}c_{4}\|x\|_{\gamma}
$$

### 3.3 常用范数之间的等价关系

**例 6**：向量空间 $V^{n}$ 中，对 $\forall x = (\xi_{1}, \xi_{2}, \cdots, \xi_{n})^{T}$，有以下等价关系：

---

**(1) 1-范数与 $\infty$-范数的关系**：

$$\|x\|_{\infty} \leq \|x\|_{1} \leq n \cdot \|x\|_{\infty}$$

**推导**：
- **上界**：$\|x\|_{1} = \sum |\xi_{i}| \leq n \cdot \max_{i} |\xi_{i}| = n \|x\|_{\infty}$
  
  （$n$ 个数相加，每个都不超过最大值，所以总和不超过 $n$ 倍最大值）

- **下界**：$\|x\|_{1} = \sum |\xi_{i}| \geq \max_{i} |\xi_{i}| = \|x\|_{\infty}$
  
  （所有数的和至少不小于其中最大的那个）

---

**(2) 2-范数与 $\infty$-范数的关系**：

$$\|x\|_{\infty} \leq \|x\|_{2} \leq \sqrt{n} \cdot \|x\|_{\infty}$$

**推导**：
- **上界**：$\|x\|_{2} = \left( \sum |\xi_{i}|^{2} \right)^{1/2} \leq \left( n \cdot \max_{i} |\xi_{i}|^{2} \right)^{1/2} = \sqrt{n} \|x\|_{\infty}$

- **下界**：$\|x\|_{2} = \left( \sum |\xi_{i}|^{2} \right)^{1/2} \geq \left( \max_{i} |\xi_{i}|^{2} \right)^{1/2} = \|x\|_{\infty}$

---

**(3) 1-范数与 2-范数的关系**：

$$\frac{1}{\sqrt{n}} \cdot \|x\|_{1} \leq \|x\|_{2} \leq \|x\|_{1}$$

**推导**：
- **上界**：由 Cauchy-Schwarz 不等式，$\|x\|_1 = \sum |x_i| \cdot 1 \leq \|x\|_2 \cdot \sqrt{n}$，所以 $\|x\|_2 \geq \frac{1}{\sqrt{n}}\|x\|_1$

- **下界**：$\|x\|_2^2 = \sum |x_i|^2 \leq (\sum |x_i|)^2 = \|x\|_1^2$，所以 $\|x\|_2 \leq \|x\|_1$

---

### 3.4 范数等价关系总结表

| 范数关系 | 不等式 | 等号成立条件 |
|---------|--------|-------------|
| 1-范数 vs $\infty$-范数 | $\|x\|_{\infty} \leq \|x\|_{1} \leq n\|x\|_{\infty}$ | 左：只有一个分量非零；右：所有分量相等 |
| 2-范数 vs $\infty$-范数 | $\|x\|_{\infty} \leq \|x\|_{2} \leq \sqrt{n}\|x\|_{\infty}$ | 左：只有一个分量非零；右：所有分量绝对值相等 |
| 1-范数 vs 2-范数 | $\frac{1}{\sqrt{n}}\|x\|_{1} \leq \|x\|_{2} \leq \|x\|_{1}$ | 左：所有分量绝对值相等；右：只有一个分量非零 |

### 3.5 有限维空间范数等价定理

**定理（非常重要！）**：**有限维线性空间中任意两个向量范数都等价。**

> ⚠️ **注意**：这个定理只对**有限维**空间成立！在无限维空间（如函数空间）中，不同范数可能不等价。

**证明思路**：只需证明任意范数 $\|x\|_{\alpha}$ 与 $\|x\|_{2}$ 等价即可（利用传递性）。

**证明**：

给定 $V^{n}$ 的基 $x_{1}, x_{2}, \cdots, x_{n}$，对任意 $x \in V^{n}$，有唯一表示：

$$x = \xi_{1}x_{1} + \xi_{2}x_{2} + \cdots + \xi_{n}x_{n}$$

定义坐标向量的 2-范数：$\|x\|_{2} = \left( \sum_{i=1}^{n} |\xi_{i}|^{2} \right)^{1/2}$

**关键构造**：考虑 $\mathbb{C}^{n}$ 的子集（单位球面）：

$$S = \left\{ (\xi_{1}, \cdots, \xi_{n}) \mid |\xi_{1}|^{2} + \cdots + |\xi_{n}|^{2} = 1 \right\}$$

$S$ 是**有界闭集**（紧集）。

定义函数：

$$f(\xi_{1}, \cdots, \xi_{n}) \triangleq \|x\|_{\alpha} = \|\xi_{1}x_{1} + \xi_{2}x_{2} + \cdots + \xi_{n}x_{n}\|_{\alpha}$$

**关键性质**：
1. $f$ 在 $S$ 上是**连续函数**（范数的连续性）
2. $S$ 是**紧集**（有界闭集）
3. 对于 $(\xi_{1}, \cdots, \xi_{n}) \in S$，$x = \xi_{1}x_{1} + \cdots + \xi_{n}x_{n} \neq 0$（因为基向量线性无关，而 $(\xi_1, \ldots, \xi_n) \neq 0$）
4. 所以 $f(\xi_{1}, \cdots, \xi_{n}) = \|x\|_{\alpha} > 0$

由 **Weierstrass 定理**（连续函数在紧集上取得最值），$f$ 在 $S$ 上取得最小值 $c_1$ 和最大值 $c_2$：

$$0 < c_{1} \leq f(\xi_{1}, \cdots, \xi_{n}) \leq c_{2}, \quad \forall (\xi_{1}, \cdots, \xi_{n}) \in S$$

**推广到一般情况**：

对 $\forall x \in V^{n}$，当 $x \neq 0$ 时，令：

$$y = \frac{x}{\|x\|_{2}} = \sum_{i=1}^{n}\frac{\xi_{i}}{\|x\|_{2}}x_{i} = \sum_{i=1}^{n}\eta_{i}x_{i}$$

其中 $\eta_{i} = \frac{\xi_{i}}{\|x\|_{2}}$，满足 $|\eta_{1}|^{2} + \cdots + |\eta_{n}|^{2} = 1$，即 $(\eta_{1}, \cdots, \eta_{n}) \in S$

于是：$c_{1} \leq f(\eta_{1}, \cdots, \eta_{n}) = \|y\|_{\alpha} \leq c_{2}$

由于 $\|y\|_{\alpha} = \left\|\frac{x}{\|x\|_2}\right\|_{\alpha} = \frac{\|x\|_{\alpha}}{\|x\|_{2}}$（齐次性），得：

$$c_{1} \leq \frac{\|x\|_{\alpha}}{\|x\|_{2}} \leq c_{2}$$

$$\Rightarrow c_{1}\|x\|_{2} \leq \|x\|_{\alpha} \leq c_{2}\|x\|_{2}$$

当 $x = 0$ 时，上式显然成立（两边都是0）。 ∎

### 3.6 范数等价的重要意义

> 💡 **为什么范数等价很重要？**

1. **收敛性独立于范数选择**：在有限维空间中，一个序列按某范数收敛 $\Leftrightarrow$ 按任何其他范数收敛

2. **开集、闭集独立于范数**：拓扑性质不依赖于具体选择哪个范数

3. **数值计算的灵活性**：可以选择计算方便的范数来分析问题，结论对其他范数也成立

4. **误差分析**：不同范数给出的误差界可以相互转换

## 四、向量序列的收敛性

### 4.1 按分量收敛的定义

**定义（按分量收敛）**：若 $\{x^{(k)}\}$ $(k = 1, 2, \cdots)$ 是线性空间 $V^{n}$ 中的向量序列，

$$x^{(k)} = (\xi_{1}^{(k)}, \xi_{2}^{(k)}, \cdots, \xi_{n}^{(k)})$$

如果**每一个分量** $\xi_{i}^{(k)}$ 当 $k \rightarrow \infty$ 时都有极限

$$
\lim_{k \rightarrow +\infty} \xi_{i}^{(k)} = \xi_{i} \quad (i = 1, 2, \cdots, n)
$$

记 $x = (\xi_{1}, \xi_{2}, \cdots, \xi_{n})$，则称向量序列 $\{x^{(k)}\}$ **有极限** $x$，或称向量序列 $x^{(k)}$ **收敛于** $x$，简称 $\{x^{(k)}\}$ 收敛，记为

$$
\lim_{k \rightarrow +\infty} x^{(k)} = x \quad \text{或} \quad x^{(k)} \rightarrow x
$$

不收敛的序列称为是**发散的**。

> 💡 **直观理解**：向量序列收敛意味着每个"坐标方向"上的数列都收敛。

**例**：设 $x^{(k)} = \left(\frac{1}{k}, 1 + \frac{1}{k^2}, \frac{k}{k+1}\right)^T$

- $\xi_1^{(k)} = \frac{1}{k} \to 0$
- $\xi_2^{(k)} = 1 + \frac{1}{k^2} \to 1$
- $\xi_3^{(k)} = \frac{k}{k+1} \to 1$

所以 $x^{(k)} \to x = (0, 1, 1)^T$

---

### 4.2 按范数收敛的定义

**定义（按范数收敛）**：若 $\{x^{(k)}\}$ $(k = 1, 2, \cdots)$ 是线性空间 $V^{n}$ 中的向量序列，如果**存在** $x \in V^{n}$，使得

$$\lim_{k \rightarrow +\infty} \|x^{(k)} - x\|_{\alpha} = 0$$

则称序列 $\{x^{(k)}\}$ **按 $\alpha$-范数收敛于** $x$。

> 💡 **直观理解**：向量序列与极限向量的"距离"趋于零。

---

### 4.3 收敛性的等价刻画（重要定理）

**定理**：在向量空间 $\mathbb{C}^{n}$ 中，以下三个条件等价：

1. **按分量收敛**：$\xi_{i}^{(k)} \rightarrow \xi_{i}$ $(i = 1, 2, \cdots, n)$
2. **按某一范数收敛**：$\|x^{(k)} - x\|_{\alpha} \rightarrow 0$（对某个特定范数）
3. **按任意范数收敛**：$\|x^{(k)} - x\| \rightarrow 0$（对任意范数）

$$
\lim_{k \rightarrow +\infty} x^{(k)} = x \quad \Leftrightarrow \quad \forall \|\cdot\|, \; \lim_{k \rightarrow +\infty} \|x^{(k)} - x\| = 0
$$

> 💡 **这个定理的意义**：在有限维空间中，收敛性与范数的选择无关！这是范数等价定理的直接推论。

**证明**：只需对 $\|x\| = \|x\|_{1}$ 证明即可（其他范数由等价性保证）。

$$x^{(k)} \rightarrow x$$

$$\Leftrightarrow \xi_{i}^{(k)} \rightarrow \xi_{i} \quad (i = 1, 2, \cdots, n)$$

$$\Leftrightarrow |\xi_{i}^{(k)} - \xi_{i}| \rightarrow 0 \quad (i = 1, 2, \cdots, n)$$

$$\Leftrightarrow \sum_{i=1}^{n} |\xi_{i}^{(k)} - \xi_{i}| \rightarrow 0$$

$$\Leftrightarrow \|x^{(k)} - x\|_{1} \rightarrow 0$$

> **说明**：第三个 $\Leftrightarrow$ 用到了：有限个趋于零的非负数列，其和也趋于零（反之亦然）。

---

### 4.4 收敛速度与范数的关系

虽然收敛性与范数选择无关，但**收敛速度**可能不同。

**例**：设 $x^{(k)} = \left(\frac{1}{k}, \frac{1}{k}, \cdots, \frac{1}{k}\right)^T \in \mathbb{R}^n$，$x^{(k)} \to 0$

- $\|x^{(k)}\|_1 = \frac{n}{k}$
- $\|x^{(k)}\|_2 = \frac{\sqrt{n}}{k}$
- $\|x^{(k)}\|_\infty = \frac{1}{k}$

虽然都趋于零，但不同范数下的衰减速度不同（相差常数倍）。

---

### 4.5 Cauchy 收敛准则

**定理（Cauchy 准则）**：向量序列 $\{x^{(k)}\}$ 收敛的充要条件是：

$$\forall \varepsilon > 0, \; \exists N, \; \text{当} \; m, n > N \; \text{时}, \; \|x^{(m)} - x^{(n)}\| < \varepsilon$$

> 💡 **意义**：不需要知道极限是什么，就能判断序列是否收敛。这在 $\mathbb{C}^n$（完备空间）中成立。

## 五、本讲小结

### 5.1 核心概念

| 概念 | 定义/性质 |
|------|----------|
| **向量范数** | 满足非负性、齐次性、三角不等式的实值函数 |
| **常用范数** | 1-范数、2-范数、$\infty$-范数、$p$-范数 |
| **范数等价** | 两范数相差常数倍界 |
| **有限维等价定理** | 有限维空间中任意两范数等价 |
| **向量收敛** | 按分量收敛 $\Leftrightarrow$ 按任意范数收敛 |

### 5.2 重要不等式

1. **三角不等式**：$\|x + y\| \leq \|x\| + \|y\|$
2. **逆三角不等式**：$|\|x\| - \|y\|| \leq \|x - y\|$
3. **Hölder 不等式**：$\sum |a_i b_i| \leq \|a\|_p \|b\|_q$，其中 $\frac{1}{p} + \frac{1}{q} = 1$
4. **Minkowski 不等式**：$\|x + y\|_p \leq \|x\|_p + \|y\|_p$

### 5.3 学习建议

1. **理解几何意义**：不同范数对应不同的"单位球"形状
2. **记住常用关系**：$\|x\|_\infty \leq \|x\|_2 \leq \|x\|_1 \leq n\|x\|_\infty$
3. **掌握证明技巧**：Hölder 不等式、归一化技巧、紧集上连续函数取最值
4. **联系应用场景**：L1/L2正则化、误差分析、算法收敛性

## 附录：常见问题解答

### Q1: 为什么 $0 < p < 1$ 时 $\|x\|_p$ 不是范数？

当 $0 < p < 1$ 时，$\|x\|_p = (\sum |x_i|^p)^{1/p}$ 不满足三角不等式。

**反例**：在 $\mathbb{R}^2$ 中，取 $x = (1, 0)$，$y = (0, 1)$，$p = 0.5$

- $\|x\|_{0.5} = (1^{0.5} + 0^{0.5})^2 = 1$
- $\|y\|_{0.5} = (0^{0.5} + 1^{0.5})^2 = 1$
- $\|x+y\|_{0.5} = (1^{0.5} + 1^{0.5})^2 = 4$

但 $4 > 1 + 1 = 2$，违反三角不等式！

### Q2: 无限维空间中范数还等价吗？

**不一定等价**！这是有限维空间的特殊性质。

**反例**：在 $C[0, 1]$ 空间中，考虑 $f_n(x) = x^n$

- $\|f_n\|_\infty = 1$（在 $x=1$ 处取得）
- $\|f_n\|_2 = \sqrt{\int_0^1 x^{2n} dx} = \sqrt{\frac{1}{2n+1}} \to 0$

这说明 $\|\cdot\|_\infty$ 和 $\|\cdot\|_2$ 在 $C[0,1]$ 中不等价。

### Q3: 范数与内积的关系是什么？

如果内积空间中有内积 $\langle \cdot, \cdot \rangle$，可以诱导出范数：$\|x\| = \sqrt{\langle x, x \rangle}$

但反过来不一定成立：不是所有范数都由内积诱导。

**判定条件（平行四边形法则）**：范数由内积诱导 $\Leftrightarrow$ 满足

$$\|x+y\|^2 + \|x-y\|^2 = 2(\|x\|^2 + \|y\|^2)$$

- 2-范数：满足，由标准内积诱导
- 1-范数、$\infty$-范数：不满足，不由内积诱导
